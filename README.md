# 🧬 bio-cs — Merging Biology & Computer Science

Welcome to my interdisciplinary playground! Having a background as a Physics, Chemistry, and Biology (PCB) student, I have always held a deep love for life sciences. Now, as an AI & Cybersecurity student, I am leveraging code to explore computational biology, bioinformatics, and biological data processing. 

This repository tracks my journey of merging biology and coding using Python.

## 🔬 Core Focus Areas

Through this repository, I am teaching myself how to apply Python to biological systems:
1. **Bioinformatics Basics:** Sequence manipulation (DNA, RNA, Amino Acids) using raw Python string methods.
2. **Data Visualisation:** Plotting growth curves, gene expression trends, and chemical compounds using Python packages.
3. **Algorithmic Logic:** Finding patterns, motifs, or mutations inside simulated genetic datasets.

## 🛠️ General Instructions

To run any of the simulation or processing scripts locally, ensure you have Python 3.x configured on your system:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the Project Folder:**
   ```bash
   cd bio-cs
   ```

3. **Run a Script (Example):**
   ```bash
   python dnaseq.py
   ```
